# WFG-05: Safeguard evaluation and evidence

## Acceptance criteria

- **WFG-05-AC1** Safe tests cover allowed/prohibited actions, malformed/failing hooks, missing handoffs, blocked/not-run handoffs, and sensitive paths.
- **WFG-05-AC2** Integration evidence distinguishes configuration registration and executable invocation from native Codex interception.
- **WFG-05-AC3** A harmless injection fixture is reviewed as data and results record observed rather than expected behavior.
- **WFG-05-AC4** Remote branch/environment settings remain pending until a human configures and verifies them.
- **WFG-05-AC5** Documentation and logs contain only work/checks/outcomes actually performed.
